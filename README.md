# Golful Pescarilor — rezervări plajă

Prototip de design Vite + React: hartă interactivă cu 512 șezlonguri, zoom vectorial și interfață desktop/mobil. Disponibilitatea, prețurile și rezervările sunt demonstrative. Nu se procesează plăți.

## Pornire

npm install
npm run dev

Build: npm run build

## Perioade

- TOATĂ ZIUA: 10:00–20:00
- DIMINEAȚĂ & PRÂNZ: 10:00–16:00
- SEARĂ: 16:00–20:00

## Publicare

GitHub Pages servește directorul docs de pe ramura main. După modificări, rulează npm run build și actualizează docs cu fișierele din dist înainte de commit/push.
